# Лабораторна робота №6: Автоматизоване тестування Python-програм

**Тема:** Професійне автоматизоване тестування Python-програм із використанням фреймворку pytest для системи банківських рахунків (Варіант 4).

**Автор:** Войтович Максим Андрійович (група ФеП-31).

## Опис проєкту

Проєкт реалізує повноцінний тестовий набір (`test suite`) для системи банківських рахунків. Основна мета роботи — перевірка коректності бізнес-логіки, обробки помилок, граничних випадків (`boundary cases`), роботи з файловою системою та конфігураціями за допомогою автоматизованих модульних (`unit`) та інтеграційних (`integration`) тестів із використанням `pytest`, `fixtures`, параметризації та аналізу покриття коду (`code coverage`).

## Основні можливості та тестове покриття

- **Модульні тести (Unit tests):** ізольована перевірка окремих компонентів (моделей об'єктів-значень `Money`, репозиторіїв та валідаторів).
- **Інтеграційні тести (Integration tests):** перевірка взаємодії компонентів у пайплайнах імпорту з CSV та експорту в JSON.
- **Фікстури та conftest.py:** повторне використання тестових даних та налаштувань.
- **Параметризовані тести:** перевірка безлічі вхідних сценаріїв та граничних значень без дублювання коду.
- **Ізоляція файлової системи (`tmp_path`):** безпечне тестування читання та запису файлів без ризику пошкодження робочих даних.
- **Керування середовищем (`monkeypatch`):** тимчасова підміна змінних середовища та конфігурацій.
- **Тестування винятків (`pytest.raises`):** перевірка коректності генерації кастомних помилок (наприклад, недостатньо коштів, невалідні суми чи валюти).
- **Контроль покриття (`pytest-cov`):** аналіз statement та branch coverage із мінімальним порогом успіху не менше 80%.
